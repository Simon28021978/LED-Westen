# Claude-Code-Mods

- **limits-band**: zeigt das 5-Stunden- und das Wochenlimit (Prozent + Reset-Zeit) dauerhaft über dem Prompt und in der Statuszeile.
- **user-name**: setzt „Simon“ als Überschrift und einen goldenen Rahmen um jede eigene Nachricht.

## Installation

Im Terminal (Claude Code):

```
/plugin install limits-band --marketplace simon28021978/led-westen
/plugin install user-name --marketplace simon28021978/led-westen
```

Desktop-App: „+“ neben dem Eingabefeld → Plugins → Add marketplace `simon28021978/led-westen` → Add plugin.

Privates Repo: Installation klappt nur mit GitHub-Zugang (SSH-Key oder `gh auth login` + `gh auth setup-git`).
